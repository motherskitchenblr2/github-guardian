# Memory Compression Constraint
- Do not read the code files during this phase. Read *only* the highly dense execution states generated by the testing matrix and conflict resolvers.

# Safe Merge Validation & Squash Blueprint
1. METRIC INTEGRITY GATE: Verify that the state flags read exactly: `tests_passed: true`, `syntax_valid: true`, `vulnerabilities_resolved: true`. If any flag is missing or false, abort the merge immediately.
2. SQUASH SUMMARY COMPRESSION: Parse the historical commit messages and PR comments. Compress them into a single-line commit title and a bulleted list of functional changes.
3. REBASE SAFENESS PROXY: Check if the base branch has drifted ahead. If the base branch hash differs from the PR branch fork point, generate a single command to trigger an isolated rebase.
4. ATOMIC MERGE INSTRUCTION: Output a concise execution payload:
   - Action: `SQUASH_AND_MERGE`
   - Commit Title: "[Fix] <Component Name>: <Short Summary>"
   - Commit Body: "- Resolved security vulnerabilities\n- Balanced syntax blocks"
